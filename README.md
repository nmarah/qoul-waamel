# قول واعمل 🃏

لعبة جماعية للجوال: اسحب بطاقة، احكي (قول) أو مثّل (اعمل)، وامشِ على المسار — أول واحد يوصل ٢٠ نقطة بيفوز ويتتوّج ملك الجلسة 👑.

- ١٠٠ بطاقة قول و ١١٩ بطاقة اعمل باللهجة الغزية
- خريطة فيها مفاجآت بتتغير كل لعبة
- تصويت، بطاقات خاصة، جولة مجنونة، و«أنا بلعبها عنك»
- الأسماء بتنحفظ على الجهاز وبتطلع كاختيار سريع
- بتنزل على الجوال كتطبيق وبتشتغل بدون إنترنت
